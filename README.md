# FedEx Tools

A simple React and Vite starter featuring a FedEx-inspired home page with four tool placeholders. Each card opens its own page, ready for a future tool implementation.

Vercel rewrites the tool page URLs to the React app so they also work when opened directly or refreshed.

## Getting started

```sh
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build in `dist`
- `npm run preview` — preview the production build
- `npm run lint` — run Oxlint
